# CapabilityCard

Displays a collection of bordered capability cards from an `items` array. Each item has a `title` and `summary`, plus optional `icon` and expandable `detail` content. Card titles must be unique within the array.

Use [CapabilityGrid](../CapabilityGrid/README.md) for plain Markdown grids and checklists.

See the [usage documentation and live examples](../../../docs/implementation-details/capability-grid.mdx#cards) for source/rendered comparisons, props, and responsive behaviour.

Implementation: [index.jsx](./index.jsx), [component styles](./styles.module.css), and [shared layout styles](../capability-layout.module.css).
