Masterpass Merchant Integration Guide –  I maintained and updated these guides 
while working at Mastercard. My main contribution was to build test integrations of all the Mastercard flows and improve the documentation with sequence flow diagrams created using PlantUML.
I also corrected any issues I found with the API reference information maintained in Open API format. The content has had some minor updates by other contributors since I left Mastercard.

The guide is publicly available on Mastercard Developers. A direct link is omitted to comply with the site’s linking terms; search for “Masterpass Merchant Integration” to view the current publication.
