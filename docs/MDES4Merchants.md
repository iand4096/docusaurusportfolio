---
title: MDES for Merchants
---

The [MDES for Merchants Use Case Guide](https://developer.mastercard.com/mdes-digital-enablement/documentation/use-cases/mdes-for-merchants-use-cases/) explains how merchants can use the Mastercard Digital Enablement API to tokenize payment cards and securely store tokens instead of payment card numbers (Primary Account Numbers, or PANs).

The Digital Enablement API is built on, and provides access to, MDES (Mastercard Digital Enablement Service), Mastercard's card tokenization platform, which was originally developed to support Apple Pay.

I wrote the first version of this guide while working at Mastercard. It has since undergone minor updates by other contributors.

View [here](https://developer.mastercard.com/mdes-digital-enablement/documentation/use-cases/mdes-for-merchants-use-cases/) on the Mastercard Developer Centre
