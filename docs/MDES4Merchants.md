---
title: MDES for Merchants
---

The MDES for Merchants Use Case Guide explains how merchants can use the Mastercard Digital Enablement API to tokenize payment cards and securely store tokens instead of payment card numbers (Primary Account Numbers, or PANs).

The Digital Enablement API is built on, and provides access to, MDES (Mastercard Digital Enablement Service), Mastercard's card tokenization platform, which was originally developed to support Apple Pay.

I wrote the first version of this guide while working at Mastercard. It has since undergone minor updates by other contributors.

The guide is publicly available on Mastercard Developers. A direct link is omitted to comply with the site’s linking terms; search for “MDES for Merchants Use Case Guide” to view the current publication.
