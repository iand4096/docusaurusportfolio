## Agile development

### Agile engineering teams

* Worked across multiple **Agile development teams**, collaborating with engineers and other stakeholders throughout the development lifecycle.
* Participated in engineering **standups** to track product and technical changes with potential documentation impact.
* Integrated documentation work with engineering development cycles so that documentation requirements and updates could be identified alongside product changes.
* Led **sprint planning** and Agile standups for documentation platform improvements and related technical work.

### Jira

* Experienced **Jira** user, creating and managing **stories and epics**, and reporting product / API defects with clear, detailed **reproduction steps** to support investigation and resolution.
* Managed and prioritized backlogs to make upcoming work and dependencies visible.
* Created **Jira dashboards** to provide clear views of prioritized work, backlog status and delivery progress.
* Used **JQL (Jira Query Language)** to create targeted filters and views for tracking specific areas of work.
* Performed **backlog refinement** to review and clarify documentation and platform work, then used Jira polls to gather stakeholder input and prioritize tasks and platform feature development.

### Jira integration and automation

* Integrated with the **Jira REST API** to programmatically retrieve tagged Jira issues.
* Used **JQL and issue metadata** to identify release-relevant changes.
* Integrated Jira data into an **automated release-note production workflow**, reducing manual effort in collecting and processing release information.

### Agile documentation workflows

* Worked alongside engineering teams to identify documentation impact as features and technical changes progressed.
* Broke documentation and platform improvements into manageable Agile work items.
* Prioritized documentation work alongside engineering priorities and release requirements.
* Tracked work through backlog, sprint and completion stages.
* Used Agile ceremonies and Jira reporting to maintain visibility of documentation progress and upcoming requirements.
