I have extensive experience creating documentation in Markdown and designing, owning and extending docs-as-code platforms, migration tooling and automated publishing workflows.
I understand and can solve the issues involved with scaling docs-as-code sites to large numbers of pages.

## Documentation platform ownership

* Served as product owner, creator and contributor for **Codetreedocs**, a custom Scala-based Markdown documentation platform and static site generator with IDE-based live preview. 
* Helped grow a docs-as-code developer portal from 700 to 3,200 pages
* Supported engineering teams contributing documentation alongside source code. Created documentation standards, contributor guidance, training and video tutorials

## Git and CI/CD workflows

* Managed documentation in Git repositories and a large Git monorepo
* Supported versioning, developer contributions, review, traceability and audit workflows
* Managed a Jenkins-based CI/CD publishing pipeline
* Improved publishing speed and maintainability through automated build processes

## Content migration and transformation

* Developed Python and Scala migration tools to convert approximately 900 pages from Sphinx and TWiki into an extended Markdown format
* Used custom code and Java and Python libraries to parse HTML and convert it into Markdown
* Preserved document structure, internal links, formatting and reusable content during migrations
* Implemented conversion logic that combined Markdown with embedded HTML where Markdown alone could not preserve the original structures; for example, to support complex tables containing multi-line cell content
* Used page-view analytics to prioritise content for migration, restructuring or retirement

## Markdown and parser engineering

* Extended Markdown parsers to support requirements beyond standard Markdown syntax such as PlantUML, Mermaid, C4 Architecture diagrams, content reuse, and code sample injection
* Tested and refined generated Markdown to ensure correct rendering and maintainability

## Static site generators

* Built an extensive test site with MkDocs as part of a work pilot. Migrated 400 pages of documentation to MkDocs format for the pilot. This work included modifying and extending a number of existing MkDocs plugins and recompiling them where necessary as C++ binaries. This work was ultimately abandoned in favour of creating a custom static site generator.
* Built the current portfolio site with Docusaurus.
* Designed and led the delivery of a custom static site generator.

## Testing and Continuous improvement

* Tested generated sites, publishing pipelines and migrated content
* Validated code examples and documentation output
* Diagnosed conversion, rendering and link-integrity problems
* Used AI-assisted development tools to automate repetitive documentation work and enhance platform functionality

This experience combines documentation-platform ownership, software development, parser extension, programmatic content transformation, Git, CI/CD, static-site generation, content migration and automated publishing.
