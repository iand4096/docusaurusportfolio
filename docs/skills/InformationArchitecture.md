My background in Information Architecture includes:
* Redesigning the information architecture for a 400-page developer documentation site, replacing a flat collection of loosely connected pages with a structured content hierarchy and clearer navigation paths that improved findability, discoverability and content organisation.
* Desiging and implemented a Graphviz-based navigation tool that allowed users to generate tree-structured, hyperlinked learning paths across related documentation, helping developers move through complex technical subject areas more intuitively.
* Analysing competitor developer portals and contributed to the content and information-architecture strategy for a new group Developer Center following the merger of Skrill and Optimal Payments.
* Defining content-lifecycle and metadata requirements for documentation search, proposing metadata-based filtering to prevent deprecated API documentation from being surfaced in generated responses.
* Desiging the information architecture supporting a RAG-based documentation search system, including generation of a comprehensive site map and analysis of retrieval issues affecting search relevance and answer quality.
* Consolidating legacy documentation into a structured Git monorepo and extended Markdown content model, improving content organisation, governance, ownership, version control and maintainability across a large documentation estate.
* Conducting a content inventory of approximately 900 pages during migration from Sphinx and TWiki, recursively spidering internal links to map content relationships and dependencies, using site analytics to prioritise high-value content, and identifying obsolete or redundant material for retirement.
