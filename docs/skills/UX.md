- Designing AI-powered LLM chatbots and speech-to-text interfaces as alternatives to traditional user interfaces.
- Creating accessible, easy-to-use developer portals.

  - Integrating interactive product demos directly into documentation.
  - Implementing intuitive site navigation, including hierarchical structures and cross-topic learning paths.
  - Designed [Explore’s faceted browsing experience](/explore?view=browse) so readers can narrow search results by content type, audience, topic, technology, or lifecycle. Filter counts show what’s available, the filter panel can be tucked away, and monochrome icons make content types easier to scan in light and dark mode.
  - Designed an [interactive viewer for Mermaid diagrams](../case-studies/RagSearchCloudArchitecture.md#architecture) that lets readers compare related workflows side by side or inspect one diagram at a time. Readers can switch layouts, zoom and pan, and reset to a centred view. I defined a site-wide visual key so colours and icons consistently identify roles such as inputs, storage, and human interaction across the portfolio. Readers can share a link that opens the same figure, panel, and layout.
- Designed for accessibility across the portfolio. I made Explore’s tabs and filters keyboard-operable, added text descriptions to architecture diagrams, and returned focus to the opener when readers close the full-screen viewer. I added browser checks for contrast in light and dark mode, narrow-screen reflow, and layouts at 200% text size.
- Advising on clear, concise user interface text.
- Writing and implementing context-sensitive help.
- Collaborating with professional UX designers.
