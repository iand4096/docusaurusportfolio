`SemanticLabel` identifies the role of a statement in a case study or writing sample. `SemanticLabelGroup` aligns related statements, such as a decision and its rationale.

## Import

```jsx
import SemanticLabel, {SemanticLabelGroup} from '@site/src/components/SemanticLabel';
```

## Inline, grouped rows and accent

Use the default inline appearance for a short statement in the narrative. Give related statements the `row` appearance and wrap them in a group. Use the accent appearance for a finding or outcome that warrants emphasis. On narrow screens, scroll the table horizontally to compare source and preview.

## Props

| Component | Prop | Default | Usage | Example |
| --- | --- | --- | --- | --- |
| `SemanticLabel` | `type` | `"decision"` | Selects the label text, colour and icon. | `"contribution"` |
| `SemanticLabel` | `appearance` | `"inline"` | Use `"inline"`, `"row"` or `"accent"`. | `"row"` |
| `SemanticLabel` | `children` | Required | The statement to label. Supports text, emphasis and links. | `Use one OpenAPI document.` |
| `SemanticLabelGroup` | `children` | Required | Related `SemanticLabel` components with `appearance="row"`. | A decision followed by its rationale. |

## Choosing a label

| Type | Use for |
| --- | --- |
| `decision` | The choice you made. |
| `rationale` | The reason for that choice. |
| `constraint` | A limit you had to work within. |
| `trade-off` | What you gained and gave up. |
| `risk` | A possible adverse outcome. |
| `outcome` | The observed result. |
| `contribution` | The work you personally delivered. |
| `validation` | How you checked the work. |

The inline style is a standalone block with a label that reads within the prose. Place it between paragraphs. Grouped rows stack when the group is 32 rem wide or narrower. Icons are decorative, and the label text carries the meaning in every layout.
