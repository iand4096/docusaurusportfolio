---
title: Paysafe.js Developer Guide
---

I wrote the first version of the Paysafe.js Developer Guide, covering the core integration workflow for securely collecting and tokenising payment details in the browser. This work was carried out while I was managing all documentation on the Paysafe developer centre leading a team of two technical writers.

I also built the original CodePen examples and an interactive **Try Now** demonstration that allowed developers to explore the integration step by step. These were later removed when the documentation moved to a new platform.

The current guide has since been expanded by other contributors to cover features including 3D Secure, Google Pay, Apple Pay and Instant Withdrawal.

View the guide on the [Paysafe developer centre](https://developer.paysafe.com/en/api-docs/paysafe-js/overview/)
